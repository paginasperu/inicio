# Regla de Versionado Automático

Cada vez que se realicen y guarden cambios en cualquier archivo de este proyecto:

1. Actualizar automáticamente `version.json` en la raíz del proyecto (`d:/Github/paginasperu.github.io/version.json`).
2. Cambiar únicamente el valor `v` usando la fecha y hora actual en formato `YYYYMMDDHHmm` (ejemplo: `"202608181018"`).
3. No modificar el código de control de versiones del HTML.
4. Asegurar que `version.json` esté actualizado antes de finalizar la tarea o antes de que el usuario suba/pushee los cambios a GitHub.
